The [Mandelbrot set](https://en.wikipedia.org/wiki/Mandelbrot_set) is a fractal
set of points in the complex plane. It is the result of iterating a quadratic map.

Commonly, the Mandelbrot set is rendered with colors corresponding to the
behavior of each point.
Additionally, there are related fractals, such as the stochastic Buddhabrot,
which produce similarly stunning renders.

I experimented with rendering these fractals, applying creative color schemes,
writing C++ and CUDA kernels for performance, and making an interactive GUI
to view the render.
